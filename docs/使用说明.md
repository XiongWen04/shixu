# 拾序使用说明

## 待办

右上角“添加”或 `Ctrl+N` 创建待办。标题必填；日期、时间、地点及备注可选。选择日期后勾选“指定时间”，分别选择小时和分钟。地点可以填写会议室、实验室、线上等文本，最多 200 字。

点击任务旁的方框完成或恢复待办；点击铅笔编辑、× 删除。删除后可撤销最近一次删除，撤销记录只保留在本次运行中。

“今天”显示今天与逾期事项；“全部”包含未设日期的待办；“月历”可以切换月份，点击某一天查看与添加任务。已完成的任务不会自动删除。

时间按 24 小时制展示。取消日期会同时取消时间和提醒，地点仍保留；逾期按日期判断。

## 到点提醒

选择日期、勾选“指定时间”，再勾选“到点提醒”。新建任务启用时间时默认开启提醒；旧任务保持原样，需要编辑后手动开启。

到点后在主屏幕右下角显示小消息，包含标题、时间、地点，无声音，不主动抢焦点。8 秒后收起，鼠标悬停时暂停收起；点击通知打开今天视图，× 只关闭通知。多条任务同时到点时合并展示。

程序每 5 秒检查一次。同一次时间安排只提醒一次，重启后也不会重复提醒；修改时间后可再次提醒。启动或从睡眠恢复时补提醒当天已到点、未完成且未提醒过的任务，前几天的逾期任务不补弹。

关闭主窗口后托盘仍运行，可以继续提醒。彻底退出、关机或睡眠期间无法弹出通知；本版本没有开机自动启动、声音或稍后提醒功能。

## 重复待办

编辑窗口“重复”支持不重复、每天、每周和每月。重复任务必须有日期；每周按初始日期的星期重复，每月按初始日号重复，短月份落在月底，之后仍回到原日号。

重复按日历生成，不依赖上次是否完成。每次都是独立任务，保留初始标题、时间、地点、备注、提醒和重要标记。软件预生成未来 62 天，并在查看更远月份时继续生成；退出期间不执行，重新打开会补齐相应周期。

编辑、星标或删除只影响当次，删除当次不会重新生成。右键任务选择“停止后续重复”，确认后保留当次、更早任务和已完成历史，删除后续未完成任务。需要修改整组的标题、时间或周期时，先停止旧规则，再新建重复任务。

## 重要任务

点击任务右侧 ☆ 切换为 ★，或在编辑窗口勾选“重要任务”。当前列表分组内，重要的未完成任务优先显示；已完成任务仍在未完成任务之后。主窗口、月历和桌面小组件都会显示星标。每次重复任务的星标可单独修改。

## 番茄钟与今日学习

左侧选择“番茄钟”，填写学习名称和时长（1–720 分钟，默认 25 分钟），点击“开始学习”。一次只计时一项学习，名称和计划时长在计时期间保持不变。

“暂停 / 继续”暂停或恢复倒计时，暂停时间不计入专注时长。“结束并记录”提前结束并保存已计时的部分，不会把计划时长全部记为已学。到点后自动记录为已完成，并显示无声音、不抢焦点的小通知，点击通知可返回番茄钟。

右侧“今日学习”显示当天累计专注时长、完成次数和提前结束次数；下方按学习名称显示每次计划时长、当天实际时长、起止时间及完成状态。进行中的时长也计入累计，跨午夜的计时分别归入各自日期。历史记录会保存在数据文件中，面板当前展示当天记录。

关闭主窗口后托盘仍运行，倒计时继续。彻底退出或系统休眠时暂停，重新打开后可继续；退出不会自动把未完成的一轮记为已完成。进度每 5 秒保存一次，暂停和结束时立即保存；强制结束进程或突然断电可能丢失最近约 5 秒的计时。

学习记录、进行中的进度与待办一起备份和迁移。导入备份会替换学习记录；有未结束的学习时须先结束再导入。当前不提供自动休息循环或学习时长排行榜。

## 桌面小组件

小组件显示今天未完成及逾期任务，可直接完成、添加，双击任务文字可编辑。拖动顶部标题区域自由移动，拖动右下角调整大小。位置和大小会保存。

组件不置顶，不自动避让桌面图标；重叠时可能遮挡图标。找不到时可从设置或托盘菜单选择“找回小组件”。

左侧按钮在开启时显示“隐藏小组件”并高亮，关闭时显示“显示小组件”。关闭主窗口后程序仍在运行，彻底退出请使用托盘菜单。

## 外观

右上角“换肤”或设置中的外观按钮可切换蓝白、暖色与深色。主窗口、桌面小组件及弹窗同步更新；支持的系统上，标题栏也使用相同配色。

## 数据

每次修改自动保存。默认数据位于程序旁的 `Data` 文件夹，设置中可以查看、打开或更换保存位置。选择空文件夹进行迁移，目标已有待办文件时不会直接覆盖。

“导出备份”创建 JSON 备份；“导入备份”校验后确认替换当前清单，不合并两份数据。更换数据位置保留原目录，读取损坏文件时提供明确的备份恢复选择。

保存失败会提示，已经保存的数据保持不变，编辑弹窗不会自动关闭。不要在程序运行时手动修改数据文件。

v1.5.0 支持读取 v1/v2/v3/v4 数据，保存为 v4，以保留提醒、星标、重复规则与学习记录。旧版不能读取 v4；升级前请导出备份，升级后继续使用 v1.5.0 或更新版本。最多保存 10000 条任务（重复任务也计入）和 10000 次学习记录。
