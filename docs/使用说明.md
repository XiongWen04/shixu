# 拾序使用说明

v2.4.0：在“换肤”菜单选择“山湖晨光”或“晴日拾光”，即可使用内置山湖摄影或绘本田园皮肤，配合半透明面板和对应强调色。背景已嵌入程序，无需联网或额外图片文件，下次启动恢复选择。保留蓝白、暖色、深色及自定义图片背景。内置皮肤不会删除先前导入的图片；选择基础主题会退出内置皮肤并显示原自定义图片（若有），选择“恢复默认背景”可清空背景选择并回到基础主题。遮罩可在“换肤 → 背景遮罩”调整，选择内置皮肤时初始为 20%。任务数据格式仍为 v7。

v2.3.0：新增“综测”页，记录活动名称、活动日期和加分分数（支持正小数），自动累计，支持修改和删除。综测记录与待办、学习计时独立，随本地数据备份、导入导出。保存格式升级为 v7，兼容旧数据；v2.2.3 及更早版本不能读取 v7，回退请使用升级前备份。

旧版更新 v2.2.3：应用图标更换为米白底绿色小鸟，程序、窗口和托盘使用同一套多尺寸图标。功能和 v6 数据格式保持不变。

月历左侧显示整月大网格，右侧显示所选日期任务。点击底部“添加待办”打开完整弹窗，日期默认取当前所选日；填写标题、日期、时间、地点、标签、备注、提醒和重复等信息后保存，取消不会新增任务。番茄钟继续使用C版。

## 自定义背景（v2.1.0）

在“换肤”菜单点击“选择背景图片…”，选择本地 PNG/JPG/BMP 图片，最大32MB。图片保持比例居中填满主窗口，边缘可能裁切；副本保存在设置文件旁的 `Backgrounds/` 中，原图移动后仍可使用。

“背景遮罩”提供20%、40%、65%、80%、90%；默认65%，越高图片越淡，文字越清晰。切换配色保留背景。“恢复默认背景”切回纯色，已导入副本保留用于设置备份恢复。缺失或损坏的图片自动回退主题。

背景仅用于主窗口，小组件保持桌面壁纸毛玻璃效果。背景设置不随待办导出；移动便携程序时一并带上 `preferences.json` 和 `Backgrounds/`。当前数据格式为 v7。

v2.2.0 使用 C 版壁纸工作台。顶部“今天 / 全部 / 月历 / 学习”居中。月历左侧显示所选日期起7天的事项，右侧小月历切换日期和月份；当天和次日显示各次重复任务，更远的重复任务集中到右侧本月摘要。“今天”保留逾期事项。事项搜索支持标题、地点、备注和标签，完成、星标、编辑、删除与撤销照常使用。学习页面计时卡片居中，目标与今日已学放在卡片底部；下方“今日学习记录”可展开查看记录、趋势和待办名称快捷填入，小窗口自动收起抽屉。学习完成不会自动改变待办状态。正向计时与倒计时用并排按钮切换，未结束学习时不可切换模式。

## 待办

“全部待办”默认折叠重复任务，显示当前筛选下的日期范围、次数和未完成数。点击汇总卡展开，再逐条完成、编辑或删除。重复规则内的各次归为一组；无规则但标题、时间、地点、备注和提醒设置相同、分布在不同日期的任务也归为一组。同一天独立任务和未设日期的任务不折叠。筛选“显示已完成”会同步影响汇总范围与数量。

右上角“添加”或 `Ctrl+N` 创建待办。标题必填；日期、时间、地点及备注可选。选择日期后勾选“指定时间”，分别选择小时和分钟。地点可以填写会议室、实验室、线上等文本，最多 200 字。

点击任务旁的方框完成或恢复待办；点击铅笔编辑、× 删除。删除后可撤销最近一次删除，撤销记录只保留在本次运行中。

“今天”显示今天与逾期事项；“全部”包含未设日期的待办；“月历”可以切换月份，点击某一天查看与添加任务。已完成的任务不会自动删除。

时间按 24 小时制展示。取消日期会同时取消时间和提醒，地点仍保留；逾期按日期判断。

## 到点提醒

选择日期、勾选“指定时间”，再勾选“到点提醒”。新建任务启用时间时默认开启提醒；旧任务保持原样，需要编辑后手动开启。

到点后在主屏幕右下角显示小消息，包含标题、时间、地点，无声音，不主动抢焦点。8 秒后收起，鼠标悬停时暂停收起；点击通知打开今天视图，× 只关闭通知。多条任务同时到点时合并展示。

程序每 5 秒检查一次。同一次时间安排只提醒一次，重启后也不会重复提醒；修改时间后可再次提醒。启动或从睡眠恢复时补提醒当天已到点、未完成且未提醒过的任务，前几天的逾期任务不补弹。

关闭主窗口后托盘仍运行，可以继续提醒。彻底退出、关机或睡眠期间无法弹出通知；本版本没有开机自动启动、声音或稍后提醒功能。

## 重复待办

编辑窗口“重复”支持不重复、每天、每周和每月。重复任务必须有日期；每周按初始日期的星期重复，每月按初始日号重复，短月份落在月底，之后仍回到原日号。

重复按日历生成，不依赖上次是否完成。每次都是独立任务，保留初始标题、时间、地点、备注、提醒和重要标记。软件预生成未来 62 天，并在查看更远月份时继续生成；退出期间不执行，重新打开会补齐相应周期。

编辑、星标或删除只影响当次，删除当次不会重新生成。右键任务选择“停止后续重复”，确认后保留当次、更早任务和已完成历史，删除后续未完成任务。需要修改整组的标题、时间或周期时，先停止旧规则，再新建重复任务。

## 重要任务

点击任务右侧 ☆ 切换为 ★，或在编辑窗口勾选“重要任务”。当前列表分组内，重要的未完成任务优先显示；已完成任务仍在未完成任务之后。主窗口、月历和桌面小组件都会显示星标。每次重复任务的星标可单独修改。

## 番茄钟与今日学习

v1.7.0 起可选择“倒计时 / 正向计时”。不知道学多久时选择正向计时，只需填写名称，不用填分钟数。计时从00:00递增，暂停、继续、退出后恢复与倒计时相同。点击“结束并记录”保存为已完成学习，显示“正向计时”而非计划分钟数，时长照常计入统计。

顶部选择“学习”，填写学习名称和时长（1–720 分钟，默认 25 分钟），点击“开始学习”。一次只计时一项学习，名称和计划时长在计时期间保持不变。

“暂停 / 继续”暂停或恢复倒计时，暂停时间不计入专注时长。“结束并记录”提前结束并保存已计时的部分，不会把计划时长全部记为已学。到点后自动记录为已完成，并显示无声音、不抢焦点的小通知，点击通知可返回番茄钟。

计时卡片“今日已学”显示当天累计专注时长、完成次数和提前结束次数；下方记录抽屉显示名称、当天实际时长、起止时间及状态，悬停可查看计划时长和计时模式。进行中的时长也计入累计，跨午夜的计时分别归入各自日期。历史记录会保存在数据文件中，面板当前展示当天记录。

关闭主窗口后托盘仍运行，倒计时继续。彻底退出或系统休眠时暂停，重新打开后可继续；退出不会自动把未完成的一轮记为已完成。进度每 5 秒保存一次，暂停和结束时立即保存；强制结束进程或突然断电可能丢失最近约 5 秒的计时。

学习记录、进行中的进度与待办一起备份和迁移。导入备份会替换学习记录；有未结束的学习时须先结束再导入。当前不提供自动休息循环。

## 学习统计与历史记录

### 每日学习目标

在计时卡片底部“每日学习目标”填入分钟数，点击“设置”。支持 1–1440 分钟，0 关闭目标。按今日实际计时显示已学、剩余分钟和进度；暂停不计入，提前结束和正向计时均计入。第二天自动重新累计，目标保持不变。目标随数据导出、导入和迁移。

### 周报与月报

学习记录抽屉或学习统计点击“周报 / 月报”。选择周报/月报，再选择该周期内任意一天，即可查看总时长、学习天数、完成次数、日均、每日图表和主要学习内容。周一至周日为一周，月报按自然月。当前周期统计至今天，日均包括没有学习的日期；对比上期对应天数，上月较短时截至上月末。参会、组会等待办不会计入学习报告。

### 待办搜索与标签

添加或编辑待办时填写标签，用中英文逗号或分号分隔；最多10个，每个最多20字，重复自动去重。“全部”页面输入关键词搜索标题、备注、地点和标签，也可选择标签组合筛选，点击“清除”恢复全部。重复任务仍折叠，数量与日期范围按筛选结果计算；修改重复待办的标签只影响当次。

学习记录抽屉点击“学习统计”，可查看近7天柱状图、近30天热力图和按学习名称合并的时长排行；查看统计时倒计时继续运行。图表按实际计时时长统计，提前结束和进行中的已计时时长也包含在内，暂停时间不计入。

顶部显示近30天总时长、学习天数和完成次数。学习天数指有计时时长的日期数，完成次数指该窗口内结束并完成的轮次。柱状图单位为分钟；各天的精确时长可悬停查看。

“统计截至”选择图表窗口的截止日期，7天和30天均包含当天。可选择过往日期回顾历史。热力图颜色越深表示时长越多，跨月首日显示月/日；点击热力格或柱状图中的日期，下方记录区会显示对应那天的记录。

排行将同名学习合并，显示前5项和各自占比，总时长仍包含所有名称；不同名称不会自动识别为同一科目。

记录区日期可以独立选择，能查看当前图表范围以外的历史记录。输入名称可筛选，再用状态菜单选择已完成、提前结束或未结束；每次先显示50条，点击“加载更多”继续查看。“今天”恢复当前日期，并清除名称和状态筛选。

进行中的图表约每5秒更新一次，暂停、继续和结束后同步更新。统计页面在较小窗口下可以滚动，记录列表也可滚动，三套皮肤均适用。

## 桌面小组件

小组件显示今天未完成及逾期任务，可直接完成、添加，双击任务文字可编辑。拖动顶部标题区域自由移动，拖动右下角调整大小。位置和大小会保存。

组件不置顶，不自动避让桌面图标；重叠时可能遮挡图标。找不到时可从设置或托盘菜单选择“找回小组件”。

右上角按钮在开启时显示“隐藏小组件”并高亮，关闭时显示“显示小组件”。关闭主窗口后程序仍在运行，彻底退出请使用托盘菜单。

## 外观

v1.6.1 起，主窗口的图标和名称只保留在系统标题栏，左侧直接显示导航，避免上下重复。

右上角“换肤”或设置中的外观按钮可切换蓝白、暖色与深色。主窗口、桌面小组件及弹窗同步更新；支持的系统上，标题栏也使用相同配色。

## 数据

每次修改自动保存。默认数据位于程序旁的 `Data` 文件夹，设置中可以查看、打开或更换保存位置。选择空文件夹进行迁移，目标已有待办文件时不会直接覆盖。

“导出备份”创建 JSON 备份；“导入备份”校验后确认替换当前清单，不合并两份数据。更换数据位置保留原目录，读取损坏文件时提供明确的备份恢复选择。

保存失败会提示，已经保存的数据保持不变，编辑弹窗不会自动关闭。不要在程序运行时手动修改数据文件。

v2.3.0 支持读取 v1–v7 数据，保存为 v7，以保留综测记录、每日目标、标签和学习记录。v2.2.3 及更早版本无法读取 v7；升级前请备份，回退时使用升级前备份。最多保存 10000 条任务（含重复任务）、10000 次学习记录和 10000 条综测记录。综测每条分数大于 0 且不超过 10000。
