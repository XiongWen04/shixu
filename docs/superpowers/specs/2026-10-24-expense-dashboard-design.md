# 记账总览与月历

用户已选择并确认「清爽总览 + 支出月历」合并预览，授权实施。

- 保留记账导航、主题、卡片和本地数据方式；顶部今日、所选月份支出与日均，支出趋势（近7天/所选月）、分类环图和餐饮细分。
- 下方月历每格精确显示该天金额（最多两位小数），选中日期联动右侧全部明细，支持空日、跨月、返回本月。新增默认跟随所选日，仍有修改和确认删除。
- 餐饮细分早饭、午饭、晚饭、其他；仅在餐饮时显示。旧记录缺少细分时归其他，不根据备注推断；切换到非餐饮时不保存细分。
- 统计使用 decimal，不统计待办/学习。日均：当月除以已过天数，其他月份除以整月天数。零数据正常展示；图表颜色适配主题，空类别不画有面积的扇区。未来日期可记账，未记录显示短横线。
- 数据 v10，兼容 v1–v9。深复制/导入替换/导出/迁移均保留细分；旧版不能读 v10，回退用升级前备份。金额和数量上限不变。
- 图表以原生 WPF 绘制，不增加第三方运行依赖；整体可纵向滚动，小窗口图表和月历/明细上下排列。

沿用用户确认的合并设计，不新增预算、收入、账户或其他功能。只以独立示例数据检查与截图。
