# 拾序开发交接

更新时间：2026-10-24。本文整理长期状态供新对话接手；具体版本和实现以当前源码、README 与 Git 为准。

## 当前交付

- 当前应用为 **v2.7.0**，程序集版本 `2.7.0.0`。
- 数据格式为 **v9**，兼容读取旧格式；v2.6.2 及更早的软件不能读取 v9，回退时要使用对应旧备份。
- 仓库公开：<https://github.com/XiongWen04/shixu>。
- 应用 Release：<https://github.com/XiongWen04/shixu/releases/tag/v2.7.0>。
- v2.2.3 将图标更换为用户选定的 B 版绿色小鸟，纸页造型翅膀，保留米白底原稿（透明抠图出现鸟身透底，未采用）。`src/AppLogo.png` 为源图，`src/App.ico` 包含 16–256 像素的十种尺寸，沿用程序、窗口和托盘的现有资源入口；功能和数据格式不变。

v2.7.0 新增左侧「记账」：`ExpenseRecord` / `TodoState.Expenses` 存于 tasks.json；decimal 金额、日期、六类分类和可选备注，支持新增、修改和确认删除。顶部今日/本月支出，下方所选月份按日分组与每日小计；月份独立于任务月历。`Expenses.cs` 提供金额优先弹窗，Ctrl+N 支持新增；核心校验、深复制、原子保存、导入替换、迁移均保留账单，旧格式缺少字段时默认空列表。格式升级 v9，单笔金额大于 0、最多两位小数、上限 99999999.99 元，备注最多 200 字，账单最多 10000 笔。`--ui-test <空目录> expenses` 为专项检查。

v2.3.0 新增顶部“综测”页：活动名称、活动日期、正小数分数，累计、修改与删除。`CreditRecord` / `TodoState.Credits` 存于现有 tasks.json，沿用校验、深复制和原子保存；所有待办、学习操作和迁移均保留记录。`CreditWindow` 是独立编辑弹窗，`--ui-test <空目录> credits` 检查本功能。

v2.4.0 新增“山湖晨光”和“晴日拾光”两套内置皮肤。`src/Skins/mountain.png` 和 `sunlit.png` 为依据用户选定概念图生成的纯背景，通过 Build.ps1 嵌入 EXE。`AppSettings.BuiltInSkin` 为可选设置，旧设置默认空；保留原 BackgroundFile，背景无需复制到个人 Backgrounds 目录。`SelectBuiltInSkin` 设置基础主题、强调色及 20% 遮罩，主面板透明度在 v2.5.0 调为 79%；基础主题和导入自定义背景退出内置模式，恢复默认会清空两类背景选择但不删文件。数据格式仍为 v7。

v2.5.0 将独立 WPF 预览正式应用到源码：左侧导航和工具、月份概览、日期任务条、当天任务卡与菜单、综测记录表。`SelectedDay` 资源适配深色卡片；保留过期提示与完整分数精度。小窗口/六周月历以一条任务和剩余数量展示日格；正常窗口显示两条。`--ui-test <空目录> layout` 检查新布局、任务菜单、完成与撤销、最小窗口及六周月份。预览目录仍在 work/redesign-preview，正式入口始终为根目录启动拾序.lnk。

v2.6.0 新增任务综测属性：`TodoItem.CreditPoints` 为 0 表示普通任务，正数表示综测活动；`CreditRecord.SourceTaskId` 关联单次任务。`TaskCredits.Sync` 在 SaveTodo / Toggle 的原子事务中同步，完成入账、撤销或取消属性撤回，编辑同步名称/日期/分数，删除任务保留历史记录。重复规则继承分数，各次任务分别入账。无日期活动首次入账使用完成当天。控制器导入同时恢复综测记录与每日目标，防止关联丢失。数据格式升级为 v8，兼容读取 v1-v7。

v2.6.1 统一 `Styles.xaml` 中 ContextMenu / MenuItem / Separator 的模板，覆盖任务操作、换肤及小组件的 WPF 弹出菜单；圆角面板、主题颜色、勾选、子菜单、禁用和键盘焦点保留。任务菜单图标与删除分组通过 `Ui.MenuIcon` 和 Danger Tag 实现，任务逻辑和数据格式不变。系统托盘仍使用 WinForms 原生菜单。

v2.6.2 编辑任务按日程安排、任务属性、补充信息分组，日期/时间并列；窗口默认 600px 宽，最小 500×580，底部操作固定。全局 TextBox 使用圆角全边框，DatePicker 保留 PART_Root/TextBox/Button/Popup 原生契约以维持日期输入与日历行为；CheckBox 补充悬停/禁用反馈，ComboBox 下拉行圆角。`Ui.Scroll` 使用 FormScroll 模板与显式细滚动条，仅用于原本禁用横向滚动的容器。数据格式与业务逻辑不变。

## 本机目录

```text
项目根目录/
├── AGENTS.md              新对话先读的开发约定
├── README.md              用户说明、截图与版本记录
├── src/                   源码、样式、图标、构建与检查
├── docs/                  使用说明、开发交接、示例截图
├── 拾序/                  本机正式程序及个人数据，Git 忽略
│   ├── 拾序.exe
│   ├── preferences.json   数据目录、皮肤、背景、小组件设置
│   ├── Data/              默认待办与学习数据、备份
│   └── Backgrounds/       导入背景副本
├── 启动拾序.lnk            本机启动入口，Git 忽略
└── outputs/               仅保留本次迁入的最新便携包和校验文件
```

旧日期工作目录仍保留用于回退，没有删除。正式开发、运行和后续更新都使用新目录；不要在两处同时运行和修改，避免产生两份不同的数据。

## 最新界面决策

1. 月历：左侧大月历，右侧所选日事项，支持按月切换和按日切换。
2. 添加：右侧底部“添加待办”按钮打开完整弹窗，默认选中日历日期。**不要恢复快速添加内嵌表单。**
3. 学习：C 版居中计时卡片、每日目标和今日已学、底部学习记录抽屉。小窗口收起抽屉并缩放卡片内容。
4. 今天页仍使用分组事项与小月历；“全部”保留搜索、标签筛选和重复任务折叠。
5. 左侧导航切换功能，底部集中放换肤、设置及小组件；当天任务卡的“···”菜单提供编辑、重要标记和删除，保留双击编辑。
6. 换肤支持蓝白、暖色、深色、内置山湖晨光/晴日拾光，以及本地图片背景、遮罩和恢复默认。主窗口背景与桌面组件效果分别处理。

## 已有功能

- 待办新增、编辑、删除、撤销最近删除、完成、日期、时间、地点、备注、标签与重要标记。
- 按日/周/月重复，独立处理每次任务；停止后续重复时保留历史及完成记录。
- 到点右下角小通知，无声音、不抢焦点；程序需保持运行。
- 桌面任务小组件支持自由拖放、缩放、显示隐藏与壁纸毛玻璃效果。
- 学习倒计时和正向计时、暂停继续、实际时长保存；退出及休眠时暂停，重新打开后可继续。
- 每日学习目标，7天趋势、30天热力图、名称排行、历史记录筛选、自然周/月报告。
- 学习时长按真实计时统计，暂停不计入、跨午夜分别归入各天；普通待办完成不算学习时长。
- 本地导入导出、数据目录迁移、原子保存及备份。
