本机启动兼容处理（2026-10-26）：原 v2.9.1 的 `拾序.exe` 在本机发生原生 `ucrtbase.dll / 0xc0000409` 启动崩溃，独立空目录同样复现。相同二进制及配置改名 `Shixu.exe` / `Shixu.exe.config` 后，空目录37项月历检查通过，正式窗口可见且响应。软件渲染开关单独使用未解决，未保留该代码改动。现保留原中文名程序，将根目录和桌面「拾序」快捷方式指向同目录 `Shixu.exe`；数据、设置、背景逐项核对保留。此为本机兼容绕过，不代表已定位具体驱动内部缺陷。应用版本和发布白名单仍沿用 v2.9.1。后续本机更新须同步替换英文名程序及配置，并使用实际运行的 `Shixu.exe --exit <运行目录>` 优雅退出；不要只替换中文名副本导致运行旧版。

旧日期工作目录仍保留用于回退，没有删除。正式开发、运行和后续更新都使用新目录；不要在两处同时运行和修改，避免产生两份不同的数据。

## 最新界面决策

1. 月历：左侧大月历，右侧所选日事项，支持按月切换和按日切换。
2. 添加：右侧底部“添加待办”按钮打开完整弹窗，默认选中日历日期。**不要恢复快速添加内嵌表单。**
3. 学习：C 版居中计时卡片、每日目标和今日已学、底部学习记录抽屉。小窗口收起抽屉并缩放卡片内容。
4. 今天页仍使用分组事项与小月历；“全部”保留搜索、标签筛选和重复任务折叠。
5. 左侧导航切换功能，底部集中放换肤、设置及小组件；当天任务卡的“···”菜单提供编辑、重要标记和删除，保留双击编辑。
6. 换肤支持蓝白、暖色、深色、内置山湖晨光/晴日拾光，以及本地图片背景、遮罩和恢复默认。主窗口背景与桌面组件效果分别处理。

## 已有功能

- 待办新增、编辑、删除、撤销最近删除、完成、日期、时间、地点、备注、标签与重要标记。
- 按日/周/月重复，独立处理每次任务；停止后续重复时保留历史及完成记录。

- 学习倒计时和正向计时、暂停继续、实际时长保存；退出及休眠时暂停，重新打开后可继续。
- 每日学习目标，7天趋势、30天热力图、名称排行、历史记录筛选、自然周/月报告。
- 学习时长按真实计时统计，暂停不计入、跨午夜分别归入各天；普通待办完成不算学习时长。
- 本地导入导出、数据目录迁移、原子保存及备份。
